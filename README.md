## 🌟 The Revamp Vision

The client's previous website is a standard WordPress install suffering from:
- Broken JavaScript counter plugins displaying `00 Projects Succeed`, `00 Satisfied Clients`
- Formatting glitches, broken character encodings, and template clutter
- Lack of interactive lead qualification or high-end luxury storytelling

This project completely reimagines **J M Interior And Decorators** into an **Awwwards-tier architectural showcase**:
1. **Editorial Luxury Aesthetic**: Warm obsidian (`#0c0b0a`), champagne gold accents (`#D4AF37`, `#C5A880`), alabaster stone typography, and architectural grain textures.
2. **Interactive Cost & Timeline Calculator** *(Aceternity / 21st.dev style)*: Configures Bangalore property type (2BHK, 3BHK, Villa, Office), scope, and finish grade to produce real-time investment estimates with 1-click WhatsApp booking to `+91 9035 672 941`.
3. **Interactive "Before & After" Transformation Slider**: Demonstrates raw concrete bare shells transforming into turnkey master suites and modern offices.
4. **Bento Capabilities Grid**: Highlighting Commercial Office Interiors, Luxury Residences, German-Engineered Modular Kitchens, In-House Furniture Joinery, and 45-Day Turnkey Handover.
5. **Project Showcase with Interactive Blueprint Modals**: Deep-dive modals with architectural breakdowns for landmark projects across Indiranagar, Bellandur, Sarjapur, and Koramangala.
6. **Milestone-Driven Execution Timeline**: 4 clear stages that alleviate client construction anxiety.
7. **Client Trust & Material Marquee**: Featuring real client endorsements from Bangalore homeowners and global hardware specifications (*Blum Austria, Hettich, Saint-Gobain, Hafele, Greenlam*).

## 🛠 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Animation Engine**: [GSAP](https://greensock.com/gsap/) with [ScrollTrigger](https://greensock.com/scrolltrigger/)
- **Smooth Momentum Scrolling**: [Lenis](https://lenis.darkroom.engineering/) synchronized with GSAP Ticker
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with custom luxury theme tokens
- **Typography**: `@fontsource/instrument-serif` & `@fontsource-variable/instrument-sans`
- **Icons & Micro-interactions**: `lucide-react`, `canvas-confetti`, `clsx`, `tailwind-merge`

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation & Development
```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Production build
npm run build

# 4. Preview production build
npm run preview
```
